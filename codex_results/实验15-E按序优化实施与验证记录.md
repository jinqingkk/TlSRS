# 实验15-E按序优化实施与验证记录

研究主体：**SGER-CasMVSNet（自几何与边缘细化残差-CasMVSNet网络）**。

日期：2026年10月20日。依据《实验15-E结果分析与下一步优化建议》第5节推进。本记录新增实验与实现，不覆盖历史结果。源码默认仍使用 `batch` 几何输入归一化；`sample` 是未通过本轮优胜筛选的实验选项。

## 1. 已落实的顺序与边界

1. 评估来源：重新导出 Epoch12 四场景、196 个参考视角的同次前向 raw/refined 深度及 raw confidence；记录 checkpoint 内部 epoch、SHA256、源码、完整参数、场景与输出文件 SHA256。输入图像为 864×1152，5 views，batch=1，192 个初始深度，级联 48/32/8，interval_scale=1.06。
2. 伤害定位：对 Epoch12/15 各取 scan1、scan10、scan49、scan118，参考视角 0/24/48，light=3，运行有 GT 的只读诊断。此处为训练格式 512×640、3 views、batch=1，各 checkpoint 共12样本、2,792,104个GT有效像素；不能当作全验证集或最终融合分辨率结果。
3. 幅度诊断：对同次前向深度固定 α=0、0.25、0.5、1。二维 GT 统计已完成；全分辨率配对融合使用独立目录和相同 raw confidence。另做重投影诊断，明确与 Gipuma 阈值分开。
4. 单变量改动：实际固定样本的几何线索存在 batch 组成漂移，因此实现“SGER几何输入按样本归一化”，不同时改变残差上限、损失权重、门控结构、主干学习率或融合阈值。
5. 短程准入：从相同 Epoch12 权重与 Adam 状态，比较 batch/sample 两组各25步，固定已训练主干参数及其BN。候选在独立验证净收益上未胜出，因此不提升为默认，不启动完整训练。

评估基础设施修复和网络候选的效果分开归因。代码测试通过、重投影通过率增加、点数变化均不等于获得 DTU 三项重建收益。

## 2. 源码改动

- `evaluation_record.py`、`test.py`：空输出目录检查、推理清单、checkpoint实际epoch及哈希、源码指纹、输出文件指纹；新增 `--save_only`，一次前向导出配对深度后可独立融合。推理与恢复训练检查 checkpoint 的归一化配置；旧checkpoint未记该字段时解释为 `batch`。缺失SGER参数的显式初始化仍需 `--allow_legacy_checkpoint`，不能静默当作已训练细化器。
- `gipuma.py`：以参数列表调用外部程序，检查退出码、保存日志，每次融合使用新工作目录，只接受本次新建目录中的非空PLY，失败不会复制旧结果。
- `experiment15_e_diagnose.py`：GT误差区间、高置信度、Sobel边缘、正负目标、门控区间及提案收益分层；同时统计净收益、伤害、提案理想二选一收益和固定α收益。GT理想选择仅用于诊断。
- `experiment15_e_amplitude.py`：固定四个α，使用相同raw confidence、相机和图像，核对源文件指纹，创建独立融合组，记录光度候选率。
- `experiment15_e_reprojection.py`：保存逐视角、逐源视图误差、有效支持、几何一致视图数直方图及候选通过数；不把支持缺失直接解释为遮挡。
- `models/module.py`、`models/sger_refinement.py`、`models/cas_mvsnet.py`：增加 `sger_depth_normalization=batch|sample`。候选仅影响SGER输入的深度均值、深度梯度、曲率及门控区域生成；均值仍detach，无新可训练参数，不改变基础深度的梯度隔离。损失内部的几何归一化维持原实现，属于本实验的明确边界。
- `train.py`、`test.py`、`gradient_audit.py`：接入该选项，默认 `batch`；训练保存该字段。旧15-D探针参数缺失时补上历史默认，保持兼容。
- `experiment15_e_normalization_probe.py`：同Adam状态、同样本、同种子、同学习率的冻结主干对照；检查优化器覆盖、无/零/非有限梯度、实际参数更新和raw不变。

`sample` 的主要额外计算是每张图的有效深度求和与计数；无额外卷积，无GT输入。这里消除的是几何均值跨样本耦合，不是修改正常的训练BN行为，也未解决分辨率变化的物理尺度问题。

原本准确且高置信度的表面在这批有GT样本中确实受到伤害；并非所有高置信度区域都应禁止修正。Epoch12/15第一行分别有840,910/826,933个像素，其中“有效修正方向正确但最终误差增加”占17.8222%/17.0475%。这为后续收益门控和准确表面保护提供依据，不证明所有伤害都由过冲造成。

固定scan1/view0输入，与scan10/view0组合，旧归一化深度通道平均绝对漂移在Epoch12/15分别为0.045739/0.047642；cue全通道最大差为0.066097/0.070187。深度梯度与曲率通道也改变。这是固定输入的受控batch耦合证据，不是跨分辨率实验。

## 4. 25步独立验证：候选未通过优胜筛选

训练：`lists/dtu/train.txt`，固定seed=1随机抽取50个样本组成25个batch，每组相同顺序。验证：`lists/dtu/val.txt`的18个场景，各取light3/view24，共18样本；代码检查它与训练清单、四场景回溯清单不相交。

两组恢复相同Epoch12 Adam参数组及动量，不重置、不追加调度；实际学习率记录在运行清单。保持完整warm-up的有效损失配置。训练主干及主干BN固定，最后阶段NormalHead和SGER可学习。验证为512×640、3 views、batch=1，GT有效像素池化。

| 项目 | 初始状态（两组相同） | batch，25步 | sample，25步 |
| --- | ---: | ---: | ---: |
| raw绝对误差/mm | 5.605382 | 5.605382 | 5.605382 |
| refined绝对误差/mm | 5.571302 | 5.543890 | 5.555585 |
| raw−refined净收益/mm | 0.034081 | 0.061493 | 0.049797 |
| 伤害贡献/mm | 0.083155 | 0.079811 | 0.084787 |

候选相对旧模式净收益减少0.011696 mm，伤害增加0.004976 mm。两组都比初始化有所改善，但这不能归因于候选；配对基线改善更多。

已核对：每组25个可训练参数张量实际变化；训练步无缺失、零或非有限可训练梯度；优化器覆盖；主干参数及BN缓冲逐位不变；18个验证raw深度逐位不变。尚未做重复种子及逐场景稳定性结论，也没有候选点云成绩。因此本轮结论是：输入一致性问题得到修复机制验证，但没有取得候选相对基线的验证优势。

## 5. 重投影和融合状态

在重新导出的Epoch12深度上，四场景各参考视角0/24/48，使用pair.txt前5个源视图；raw/refined共用raw confidence≥0.9候选。回投影要求有效正深度、相机空间Z>0、坐标在图内及插值邻域有效。

诊断通过条件固定为回投影像素距离<1、相对深度误差<0.01，至少4个源视图一致。**它不是Gipuma的disp_threshold=0.25，也不是Gipuma实际最终掩码。**

- 共10,171,717个参考候选像素；raw/refined诊断通过率为53.5698%/55.7604%。12个参考视角均为refined更高。
- 在raw/refined共同可回投影支持上，像素距离均值14.827188→14.766611，相对深度差均值0.028671→0.028570。该平均包含未通过阈值的大误差点，不应解释为通过像素的误差。
- 此次抽样暂不支持“跨视图一致性普遍下降”的解释；增加通过率仍不证明表面更准确。

全幅度融合固定 `prob_threshold=0.9`、`disp_threshold=0.25`、`num_consistent=4`。点数与最终状态见本记录末尾的完成汇总。Gipuma内部逐像素几何/最终掩码与一致视图直方图未导出，不用上述重投影代理替代。

本环境未找到MATLAB/Octave可执行程序，本地DTU数据目录也未提供官方点云评估所需的SampleSet。因而本轮不报告新的Acc./Comp./Overall，不将生成点云或点数变化判定为成功。需在原有DTU评估环境使用完全一致的官方协议计算四组、四场景成绩。

## 6. 复现命令

所有输出目录必须是新目录。以下目录与本次运行对应，复跑时换名；不要覆盖已保存清单。旧正式执行说明第6节存在“model_000015写入epoch12目录”和fusibile路径换行问题，下列命令明确使用model_000012且在一次前向后配对融合。

```bash
OMP_NUM_THREADS=1 python experiment15_e_diagnose.py \
  --checkpoints checkpoints/experiment15_e_formal_stable_bce/model_000012.ckpt checkpoints/experiment15_e_formal_stable_bce/model_000015.ckpt \
  --trainpath data/DTU/mvs_training/dtu --scan_list lists/dtu/test.txt \
  --output_dir outputs/experiment15_e/diagnose12_15_gpu

OMP_NUM_THREADS=1 python experiment15_e_normalization_probe.py \
  --checkpoint checkpoints/experiment15_e_formal_stable_bce/model_000012.ckpt \
  --trainpath data/DTU/mvs_training/dtu --steps 25 \
  --output_dir outputs/experiment15_e/normalization_probe25

OMP_NUM_THREADS=1 python -u test.py \
  --dataset general_eval --testpath data/DTU/dtu_test_all --testlist lists/dtu/test.txt \
  --loadckpt checkpoints/experiment15_e_formal_stable_bce/model_000012.ckpt \
  --outdir outputs/experiment15_e/epoch12_verified_pairs --interval_scale 1.06 \
  --use_sger_lite --sger_max_residual_ratio 0.25 --sger_depth_normalization batch \
  --batch_size 1 --num_view 5 --max_h 864 --max_w 1152 --save_only --save_freq 1000

LD_LIBRARY_PATH="/usr/lib/wsl/lib:$CONDA_PREFIX/lib/python3.7/site-packages/torch/lib:${LD_LIBRARY_PATH:-}" \
OMP_NUM_THREADS=1 python -u experiment15_e_amplitude.py \
  --source_dir outputs/experiment15_e/epoch12_verified_pairs \
  --output_dir outputs/experiment15_e/epoch12_amplitude --scan_list lists/dtu/test.txt \
  --fuse --fusibile_exe_path ../../fusibile-master/build/fusibile \
  --prob_threshold 0.9 --disp_threshold 0.25 --num_consistent 4

OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python -u experiment15_e_reprojection.py \
  --source_dir outputs/experiment15_e/epoch12_verified_pairs --testpath data/DTU/dtu_test_all \
  --scan_list lists/dtu/test.txt --output_dir outputs/experiment15_e/epoch12_reprojection
```

若使用没有推理清单的历史目录，幅度脚本默认拒绝。`--allow_unverified_source`只允许明确标记来源未核验的回溯诊断，不能把目录名提升为checkpoint证据。本次新融合未使用该例外。


本轮不同时推进第二个网络改动。下一轮更直接的候选是：固定提案生成状态，针对“准确表面受扰、有害提案仍被放行”只改变收益门控的输入或监督中的一项；先在独立验证上改善净收益和伤害量，再决定是否完整训练。归一化候选的负结果要保留，不能仅凭消除batch漂移将它作为性能改进发布。
