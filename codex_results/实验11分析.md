# 实验11分析：SGER-Lite Stage3-only

## 1. 实验11设置回顾

实验11是在现有 SGER 实现上收敛出的 `--use_sger_lite` 路径，核心约束是只在 Stage3 引入 NormalHead 和 SGERBlock：

- Stage1、Stage2 保持原 CasMVSNet，不运行 NormalHead，不输出 SGER 字段。
- Stage3 输出 `depth_raw` 和 `depth_refined`，其中顶层 `outputs["depth"]` 使用 refined depth。
- Stage1 -> Stage2 -> Stage3 的级联搜索中心不使用 refined depth，因此不会把 SGER 残差反馈到后续搜索范围。
- 关键参数：`sger_max_residual_ratio=0.5`，`raw_depth_loss_weight=1.0`，`refined_depth_loss_weight=1.0`，`residual_loss_weight=0.005`。
- 前 6 个 epoch 冻结主干，只训练 Stage3 NormalHead + SGERBlock。
- 推理阶段分别比较：
  - a：refined depth + raw photometric confidence
  - b：refined depth + residual calibrated confidence
  - c：raw depth + raw photometric confidence

当前代码对应结构：

- `models/cas_mvsnet.py`：`use_sger_lite=True` 时，只有最终 stage 执行 NormalHead + SGERBlock。
- `models/sger_refinement.py`：SGERBlock 使用 depth、normal、confidence、图像边缘、深度梯度、曲率和参考特征预测 gated residual。
- `models/module.py`：loss 同时监督 raw depth、refined depth、residual ratio、normal consistency、curvature、edge-aware smooth 等。

## 2. 主要结果

### 2.1 训练指标

实验11训练到 Epoch 12 时：

| 指标 | Epoch 0 | Epoch 3 | Epoch 6 | Epoch 9 | Epoch 12 |
|---|---:|---:|---:|---:|---:|
| loss | 47.6796 | 38.3588 | 36.1774 | 37.2676 | 35.5433 |
| depth_loss | 8.3772 | 6.6607 | 6.2679 | 6.4646 | 6.1549 |
| abs_depth_error | 8.7435 | 7.0163 | 6.6242 | 6.8047 | 6.5046 |
| normal_depth_cos | 0.5924 | 0.6285 | 0.6453 | 0.6588 | 0.6721 |
| stage3/mean_abs_depth_residual | 0.4229 | 0.3331 | 0.3027 | 0.2747 | 0.2814 |
| stage3/geometry_gate_mean | 0.7151 | 0.7191 | 0.7198 | 0.7204 | 0.7205 |

和实验8相比，实验11的 depth loss 明显更高。实验8 Epoch 12 的 depth loss 是 3.9605，实验11 Epoch 12 是 6.1549。说明加入 Stage3 SGER-Lite 后，训练表面的监督指标没有延续实验8的优势。

更关键的是，SGER 的 gate 均值长期维持在约 0.72，显著偏高。SGERBlock 本应在可靠几何区域做有限残差修正，但当前结果显示它在大范围像素上都倾向于放行 residual。

### 2.2 DTU 评价结果

实验11三种融合方式结果：

| 设置 | Epoch | acc | comp | overall |
|---|---:|---:|---:|---:|
| a refined + raw confidence | 14 | 0.2997 | 0.3685 | 0.3341 |
| a refined + raw confidence | 12 | 0.3012 | 0.3662 | 0.3337 |
| b refined + residual calibrated confidence | 14 | 0.2481 | 0.5003 | 0.3742 |
| b refined + residual calibrated confidence | 12 | 0.2457 | 0.5072 | 0.3765 |
| c raw + raw confidence | 14 | 0.2939 | 0.3524 | 0.3232 |
| c raw + raw confidence | 12 | 0.2942 | 0.3567 | 0.3255 |

对比 baseline：

| 设置 | Epoch | acc | comp | overall |
|---|---:|---:|---:|---:|
| baseline | 15 | 0.3015 | 0.3569 | 0.3292 |
| baseline | 12 | 0.2988 | 0.3559 | 0.3274 |
| 实验8 | 15 | 0.2923 | 0.3537 | 0.3230 |
| 实验8 | 12 | 0.2961 | 0.3579 | 0.3270 |
| 实验11-c raw + raw confidence | 14 | 0.2939 | 0.3524 | 0.3232 |
| 实验11-c raw + raw confidence | 12 | 0.2942 | 0.3567 | 0.3255 |

结论：

- 实验11-c 是实验11里最好的设置，说明 raw depth 仍然比 refined depth 更可靠。
- 实验11-c Epoch 14 overall = 0.3232，接近实验8 Epoch 15 的 0.3230，且优于 baseline Epoch 15 的 0.3292。
- 实验11-a 使用 refined depth 后 overall 变差到 0.3341 / 0.3337，说明 SGER refined depth 当前没有稳定改善 raw depth。
- 实验11-b 的 acc 很好，但 comp 明显恶化，overall 最差。这说明 residual calibrated confidence 过滤过强，删掉了大量点，导致完整性严重下降。

### 2.3 点云数量

## 3. 结果解释

### 3.1 Stage3-only 避免了级联搜索干扰，但没有保证 refined depth 更好

实验11达成了“不干扰级联搜索”的结构目标：Stage1 和 Stage2 仍然使用原 CasMVSNet raw depth，Stage3 才做 SGER refinement。

但是这只解决了实验10里 refined depth 跨阶段反馈的问题，并不自动保证 Stage3 residual 是正向修正。当前数据表明：

- raw + raw confidence 是最优设置；
- refined + raw confidence 反而变差；
- 因此 Stage3 SGER residual 在 DTU overall 上总体是负贡献。

这说明问题已经从“是否干扰级联搜索”转移到“SGERBlock 本身是否学到了可靠残差”。

### 3.2 geometry gate 过高，残差作用范围太大

实验11中 `stage3/geometry_gate_mean` 稳定在 0.72 左右，而实验10中 Stage3 gate 均值约 0.22-0.39。Lite 版本虽然只在 Stage3 使用 SGER，但 gate 反而更开放。

这会带来两个风险：

- residual 在过多像素上生效，不再是局部几何修正。
- 即使 `sger_max_residual_ratio=0.5`，大范围小残差也可能破坏原本较好的 raw depth。

当前 `mean_abs_depth_residual` 约 0.28-0.42，残差幅度不算失控，但 gate 面积太大，使得 refined depth 全局偏移风险增加。

### 3.3 normal branch 尚未形成足够可靠的几何约束

实验11 Epoch 12 的 `normal_depth_cos=0.6721`，仍然偏低。相比实验8 Epoch 12 的 `normal_depth_cos=0.9814`，实验11的 normal-depth 一致性明显不足。

这意味着 SGER 输入中的 `normal_pred` 和由深度反算的 `normal_depth` 分歧较大。SGERBlock 依赖这类几何 cue 做 gating 和 residual 预测，如果法线 cue 不稳定，refinement 很容易学习到噪声修正。

可能原因：

- 前 6 个 epoch 冻结主干时，Stage3 NormalHead 和 SGERBlock 从随机初始化开始学习，但输入特征来自固定主干，normal head 收敛较慢。
- 解冻后 raw/refined depth 同时监督，SGER residual 缺少“只在确定能改善 raw depth 时才修正”的明确约束。
- `depth_normal_loss_weight`、geometry gate、residual loss 的组合没有直接惩罚“refined 比 raw 更差”的区域。

### 3.4 residual calibrated confidence 当前过于激进

当前 residual calibrated confidence 逻辑相当于：

```text
confidence_calibrated = confidence * exp(-residual_ratio)
```

当 gate 大、residual ratio 分布较广时，这会把很多区域的 confidence 压低。实验11-b 的点云数量下降约 21%，说明该校准方式把大量点过滤掉了。

这类策略对 acc 有帮助，但对 comp 伤害过大。DTU overall 是 acc 和 comp 的均衡指标，因此不适合使用如此强的 residual confidence 衰减。

## 4. 当前结论

实验11的核心验证结论是：

1. Stage3-only 的结构方向是正确的，因为 raw + raw confidence 可以保持甚至接近实验8的最佳 overall。
2. 当前 SGER refinement 本身还没有学到稳定正向残差；refined depth 不优于 raw depth。
3. 当前 residual calibrated confidence 过强，不适合作为默认融合置信度。
4. 下一步不应继续扩大 SGER 作用范围，而应收紧 residual、收紧 gate，并显式约束 refined depth 必须优于或至少不劣于 raw depth。

当前默认评估建议使用：

```text
raw depth + raw photometric confidence
```

这对应当前代码默认：

```bash
--fusion_depth_source raw
--fusion_confidence_source raw
```

如果继续报告 SGER-Lite 的 refined 效果，必须同时报告 raw/refined 对比，不能只看训练 depth_loss。

## 5. 下一步优化方案

### 5.1 第一优先级：把 SGER residual 做成更保守的局部修正

建议下一组实验先降低残差上限：

```bash
--sger_max_residual_ratio 0.25
```

如果仍然 refined 变差，再试：

```bash
--sger_max_residual_ratio 0.10
```

原因：实验11已经证明 0.5 的残差上限仍可能使 refined depth 破坏 raw depth。SGER-Lite 的目标不是大幅改深度，而是验证能否做稳定小修正。

### 5.2 第二优先级：加入 gate 稀疏约束，降低 geometry_gate_mean

当前 `geometry_gate_mean≈0.72` 过高。建议新增 gate regularization：

```text
L_gate = mean(geometry_gate)
```

初始权重建议：

```bash
--gate_loss_weight 0.001
```

观察目标：

```text
stage3/geometry_gate_mean 降到 0.15 - 0.35
```

如果 gate 降低后 refined depth 不再明显恶化，再逐步调大 residual capacity。

### 5.3 第三优先级：增加 raw-refined 安全约束

目前 loss 同时监督 raw 和 refined：

```text
L_depth = L_refined + L_raw
```

但它没有显式惩罚 refined 比 raw 更差。建议增加一个 margin ranking 类型的安全项：

```text
err_raw = |depth_raw - depth_gt|
err_refined = |depth_refined - depth_gt|
L_safe = mean(max(0, err_refined - err_raw + margin))
```

初始建议：

```text
margin = 0
safe_refine_loss_weight = 0.1
```

这个约束直接服务实验目标：让 Stage3 refined depth 稳定优于 Stage3 raw depth。

### 5.4 第四优先级：调整 residual calibrated confidence

当前校准过强，不建议继续使用 `exp(-residual_ratio)` 原式作为主结果。建议改成带强度和下限的温和校准：

```text
confidence_calibrated = confidence * (conf_floor + (1 - conf_floor) * exp(-alpha * residual_ratio))
```

初始参数：

```text
alpha = 0.25
conf_floor = 0.5
```

这样 residual 大的区域会降权，但不会直接造成 20% 以上点云丢失。评估时仍需同时报告：

- raw + raw confidence
- refined + raw confidence
- refined + calibrated confidence

### 5.5 第五优先级：训练策略改为两阶段

建议下一轮 SGER-Lite 采用更明确的两阶段训练：

第一阶段，只训练 Stage3 NormalHead + SGERBlock：

```bash
--freeze_backbone_epochs 8
```

第二阶段，解冻但降低主干学习率。当前代码还没有分组学习率，建议实现：

```text
backbone_lr = 0.1 * sger_lr
```

如果不想改 optimizer，保守做法是继续冻结主干更久，只训练 SGER 分支，先验证 refined 是否能在固定 raw depth 上做正向残差。

## 6. 推荐的实验12配置

建议实验12不要引入更多新模块，而是做 SGER-Lite 收敛性修正：

```bash
python train.py \
  --mode train \
  --dataset dtu_yao \
  --trainpath <DTU_TRAIN_PATH> \
  --testpath <DTU_TRAIN_PATH> \
  --trainlist lists/dtu/train.txt \
  --testlist lists/dtu/val.txt \
  --loadckpt <experiment8_best_ckpt> \
  --logdir ./checkpoints/sger_lite_stage3_safe \
  --use_sger_lite \
  --sger_max_residual_ratio 0.25 \
  --raw_depth_loss_weight 1.0 \
  --refined_depth_loss_weight 1.0 \
  --residual_loss_weight 0.01 \
  --freeze_backbone_epochs 8 \
  --ndepths "48,32,8" \
  --depth_inter_r "4,2,1" \
  --dlossw "0.5,1.0,2.0" \
  --batch_size 2
```

如果加入 gate loss 和 safe refine loss，建议：

```text
gate_loss_weight = 0.001
safe_refine_loss_weight = 0.1
safe_refine_margin = 0
```

## 7. 评估协议建议

实验12开始建议固定以下评估协议，避免单一指标误导：

1. 每个 checkpoint 至少导出三套结果：
   - raw + raw confidence
   - refined + raw confidence
   - refined + calibrated confidence
2. checkpoint 选择以 DTU overall 为准，不以训练 depth_loss 为准。
3. 同时记录点云数量。如果点云数量下降超过 5%，需要单独解释 comp 变化。
4. 必须报告 `stage3/raw_to_refined_error_delta`：
   - 正值表示 refined 比 raw 好；
   - 负值表示 refined 比 raw 差。
5. 必须报告 `stage3/geometry_gate_mean` 和 `stage3/mean_abs_depth_residual`，用于判断 SGER 是否过度修正。

## 8. 最终判断

实验11没有证明 refined depth 优于 raw depth，但它明确排除了一个关键干扰因素：Stage3-only 不会破坏级联搜索。当前失败点集中在 Stage3 refinement 本身：

- gate 太开放；
- residual 没有被限制为安全改进；
- normal cue 还不够稳定；
- residual calibrated confidence 过度过滤点云。

所以下一步应该收紧 SGER，而不是扩大 SGER。优先做小残差、稀疏 gate、安全 refined loss 和温和 confidence calibration。
