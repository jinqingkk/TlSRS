# 实验15最新进展｜4页PPT内容

## 第1页｜工作总览：建立SGER“诊断—修复—对照验证”实验体系

**研究目标：在保护raw主干质量的基础上，使SGER获得稳定、可归因的细化收益。**

| 工作模块 | 已完成的工作与规模 | 阶段产出 |
|---|---|---|
| 15-C：梯度与激活审计 | 3个checkpoint × 5个固定Batch × 2种激活；30份变体报告、450个审计case | 定位残差末端激活与门控损失的局部梯度阻断 |
| 15-D：BCE数值机制验证 | 25组新旧BCE配对审计 | 验证稳定BCE可恢复饱和区门控梯度 |
| 局部训练对照 | 1轮三组×200步；4轮三组×25步 | 分别检验BCE、动量、正负均衡与门控归一化假设 |
| 门控选择性诊断 | 6份快照，固定训练/验证子集，逐场景及区域交叉统计 | 区分可利用提案、有害修正与实际门控贡献 |
| 新增方向监督 | 三组×2步已通过；25步对照进行中 | 固定门控，仅更新残差头，检验双向纠错恢复 |

**工作量数字栏：450个激活审计case｜25组BCE配对｜已完成主要训练对照累计900次参数更新。**

900次口径：3×200 + 4×3×25；包含重复组，不是900步连续训练。四轮25步分别为动量、正负均衡、饱和BCE、门控归一化；不含两步预检和正在运行的方向BCE实验。不同模块的审计和训练计数不相加为独立实验数量。

**实验可信性建设：**保存源码/输入哈希、模型与Adam状态；设置确定性重复组；检查raw/置信度、冻结参数和BN保护；采用固定3场景6样本、1,545,967个有效像素的验证统计。

**页底结论：已建立从梯度、参数更新到实际深度收益的验证流程，将“SGER不生效”拆解为可逐项检验的问题。**

配图：横向研究路线——学习异常 → 激活/BCE定位 → 饱和恢复 → 选择性诊断 → 残差方向监督。

## 第2页｜实验15-C：系统定位残差与门控的两处学习障碍

**完成内容：**从单Batch检查扩展至E9/E12/E15的5批配对审计，分别检查残差主体、输出层、收益门控和主干梯度边界。

| E12配对结果 | 原ReLU | 末端LeakyReLU |
|---|---:|---:|
| 残差主体梯度L2 | 0 | 0.0735–0.0899 |
| 平均绝对残差提案 | 0.001524 | 0.143630 |
| 收益正标签率 | 0% | 19.05% |
| 门控均值 | 3.91×10⁻¹³ | 3.91×10⁻¹³ |
| 旧BCE门控专属梯度 | 0 | 0 |

- **定位一：残差端。**E9/E12末端ReLU输出全零，主体与输出权重梯度为零；LeakyReLU恢复有限非零梯度和空间变化。
- **定位二：门控端。**残差恢复后已有收益正标签，但极低门控进入BCE硬clamp区间，门控梯度仍为零。
- **副作用验证。**对E15已有活跃模型直接换激活，refined误差从1.985333升至1.995999；同一raw为2.004833，细化收益减少54.7%。

**页底结论：完成两处局部学习障碍定位，并验证“梯度恢复”不能替代“方向正确、实际收益改善”。**

配图：残差r与门控g两条分支图，分别标注“激活负区间阻断”“BCE硬截断”；旁侧展示E15激活替换收益对比。

页脚口径：scan2训练划分、5个固定Batch、train模式、Stage3有效像素加权；包含相同几何的不同光照。梯度为专属损失权重及调度强制为1的五批范围。无参数更新，未恢复历史训练计算图；深度误差沿用数据单位。

讲述提示：已排查的是这些样本和快照上的局部机制，不能说网络在所有数据上永久失活。15-C的贡献还包括发现直接替换激活会破坏后期已有收益，避免将局部修复直接作为最终网络。

## 第3页｜实验15-D：完成饱和门控恢复，并追踪到选择性不足

**工作一：新旧BCE三组25步对照，验证恢复是否落实到实际输出。**

| 固定验证指标 | 共同起点 | 旧BCE第25步 | 稳定BCE第25步 |
|---|---:|---:|---:|
| 活动logit均值 | −60.329 | −59.993 | −23.408 |
| 门控均值 | 2.55×10⁻¹³ | 近零 | 0.010793 |
| 平均绝对有效残差 | 1.20×10⁻¹⁴ | 9.20×10⁻¹⁵ | 0.001529 |
| raw−refined收益 ↑ | 0 | 0 | −0.000213 |

- 首个训练Batch的68,484个饱和收益正标签：旧BCE活动logit梯度全零，稳定BCE全部有限且方向正确。
- 第25步低门控饱和比例由100%降至63.49%；raw误差3.116233，refined误差3.116445，三个验证场景均轻微恶化。

**工作二：读取6份快照，交叉分析提案收益、正负目标、门控区间与A/B分支。**

| 稳定BCE第25步区域 | 像素数 | 对全体验证平均收益的贡献 |
|---|---:|---:|
| 有益提案区域 | 611,964（39.58%） | +0.000610 |
| 有害提案区域 | 933,970（60.41%） | −0.000823 |

另有33个中性像素。有害区域负贡献超过有益区域正贡献；883,565个负目标像素没有负提案，残差方向准确率仍为42.84%。

**页底结论：稳定BCE已恢复门控梯度与实际细化量；当前瓶颈进一步明确为收益选择不足和负向纠错缺失。**

配图：左侧logit随0/1/2/5/10/25步变化曲线；右侧正负收益贡献条形图，直观说明“为什么门控打开后仍未改善”。

页脚口径：固定scan3/5/17共6样本，eval模式、Stage3有效像素加权，Δ=raw误差−refined误差，正值改善。共同起点为E12经一次LeakyReLU恢复更新后的快照。压力对照检查通过，旧BCE重复组144项比较完全一致；该实验不能替代原ReLU架构的激活/BCE消融。

讲述提示：只读诊断还测得GT离线理想二选一收益+0.046284，说明当前提案中存在局部可利用修正；该数值使用GT选择，不能作为模型精度或可部署方法成绩。此前E15原ReLU冻结200步对照中新旧BCE结果近乎一致，因此后续专门选择饱和起点检验恢复机制。

## 第4页｜最新进展：分离门控与残差优化，推进双向纠错验证

**工作一：门控归一化25步单变量对照已完成。**

固定残差、主干、法线和共享特征，仅更新8个门控参数张量；比较类别平衡与像素平均稳定BCE。

| 第25步固定验证结果 | 类别平衡BCE | 像素平均BCE |
|---|---:|---:|
| 门控均值 | 0.073228 | 0.041860 |
| refined误差 ↓ | 3.117887 | 3.117141 |
| raw−refined收益 ↑ | −0.001654 | −0.000908 |

像素平均使恶化幅度相对基准减少**45.10%**，但三个场景仍全部差于raw；只能说明减轻错误修正，尚未实现正收益。

**工作二：完成残差方向BCE实现和两步对照，25步运行中。**

- 固定raw、门控、共享特征、法线及BN，仅更新残差头8个参数张量。
- 对tanh前残差logit增加方向BCE，固定权重0.05；正/负目标梯度分别推动正/负方向，GT只用于训练监督。
- 三组两步真实对照已完成且检查通过。第2步方向准确率仍为42.84%，负目标方向准确率为0%；尚不能宣布双向纠错恢复。
- 截至21:24：25步实验基准/重复组均完成25步，方向BCE组已记录8步；整轮尚未完成，最终比较待汇总。

**阶段结论与后续判据**

已形成“残差激活阻断 → 门控数值阻断 → 门控恢复后的选择不足 → 残差双向表达验证”的连续研究证据。后续先检查负目标区域是否产生足量正确负提案，同时保留正向纠错；再验证固定门控下refined是否优于raw，最后开展公平DTU点云评估。

**页底结论：已完成机制定位、数值修正及多轮单变量排查；最新工作聚焦SGER残差方向表达，最终重建优势尚待验证。**

配图：三列状态卡——“已完成：归一化对照”“已通过：方向BCE两步验证”“进行中：方向BCE 25步”。

页脚口径：同一3场景6样本固定验证集；归一化与方向实验均从稳定BCE压力组第25步快照独立恢复，各自只在组内归因。归一化主要改变门控开放幅度；45.10%是减少恶化，不能写成重建精度提升45.10%。方向25步状态为文件快照，汇报前可再次核对。
