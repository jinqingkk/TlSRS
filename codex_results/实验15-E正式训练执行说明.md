# 实验15-E：SGER-lite稳定BCE正式训练

日期：2026-10-10。研究主体：**SGER-CasMVSNet（自几何与边缘细化残差-CasMVSNet网络）**。

## 1. 训练准入结论

本轮进入16个epoch的正式端到端训练，但不把实验15-D未通过的方向线索接入生产网络。双侧多视图匹配探针、显式有符号概率体探针和方向BCE均未建立跨场景方向可分性，因此本轮不增加输入通道、不实现方向×幅度头、不搜索方向损失权重或双侧扰动倍率。

正式训练只验证当前生产SGER-lite在完整从零训练轨迹中的综合表现。相对当前活动生产默认值，本轮唯一显式实验选择是将收益门控BCE设为已经完成数值机制审计的`stable_logprob`；网络结构、损失权重、门控定义、残差范围和融合协议均不改。该选择修复饱和正标签的梯度阻断，但短程实验尚未证明重建收益，因此正式训练结果必须按raw/refined对照判定，不能预先记为成功。

## 2. 固定配置

- Stage3-only `SGER-lite`，保留活动源码中的raw主干梯度隔离；
- 残差末端使用`ReLU`。LeakyReLU只证明过早期局部梯度恢复，但在已有Epoch15权重上降低细化收益，故不进入本轮；
- `gate_bce_mode=stable_logprob`；
- `freeze_backbone_epochs=0`，避免复现实验14的早期主干崩溃；
- `backbone_lr_scale=0.1`，实验15-B的1.0倍率已导致raw重建退化；
- 16个epoch，从零训练，不加载旧checkpoint；
- seed=1、3训练视图、48/32/8深度采样、4/2/1区间倍率、batch size 2；
- SGER残差尺度在epoch 7至10 warm-up，残差目标从epoch 4启用，收益门控损失从epoch 7至10 warm-up；
- 不使用实验15-D探针特征，不改变置信度或点云融合阈值。

## 3. 启动与恢复

默认从零启动：

```bash
bash train_experiment15_e.sh
```

指定新目录：

```bash
bash train_experiment15_e.sh ./checkpoints/experiment15_e_formal_stable_bce start
```

仅在同一目录中已有本轮checkpoint且启动参数未修改时恢复：

```bash
bash train_experiment15_e.sh ./checkpoints/experiment15_e_formal_stable_bce resume
```

若DTU数据不在仓库默认位置，先设置：

```bash
export MVS_TRAINING=/实际路径/DTU/mvs_training/dtu/
```

入口拒绝在已有checkpoint目录上执行`start`，并将完整命令和活动源码SHA256写入`formal_training_manifest.txt`。不得通过`resume`切换BCE、激活、损失权重、warm-up或学习率配置。

## 4. 训练中检查点

训练日志至少检查epoch 0、3、6、9、12、15：

- loss及所有梯度相关量有限；
- raw深度误差不出现实验14中约80的灾难性跳变；
- `geometry_mask_ratio`保持合理且无突然归零；
- epoch 0至6的`sger_residual_scale=0`，epoch 7至10按计划升至1；
- 实际残差目标、收益门控和refined损失权重与调度一致；
- epoch 7后同时检查提案、门控和有效残差，不能只看`mean_abs_depth_residual`；
- `raw_to_refined_error_delta`正值表示改善，必须同步检查改善/恶化像素比例、方向准确率和门控选择性。

仅在出现非有限值、raw主干灾难性崩溃、配置与本说明不一致或checkpoint无法安全恢复时中止。单个epoch的refined暂时低于raw不作为立即停训依据，但必须如实记录。

## 5. 正式评估

固定导出epoch 9、12、15；每个checkpoint至少生成两组独立结果：

1. `refined depth + raw confidence`；
2. `raw depth + raw confidence`。

两组固定相同场景、视图数、图像尺寸、深度采样、置信度阈值、几何阈值及融合程序。在refined稳定优于raw前不搜索融合阈值。逐场景和汇总记录Acc.、Comp.、Overall、点数、光度/几何/最终掩码通过率及视图一致性计数。

正式成功仍要求同checkpoint下refined的Acc.、Comp.、Overall全部低于raw，并检查跨checkpoint一致性。若raw稳定而refined仍差，则本轮只证明稳定BCE可以完成正式训练，不证明SGER贡献成立；后续应按已预注册方向进入独立的局部空间上下文探针，而不是把失败的双侧逐像素线索直接加入网络。

## 6. Epoch 12首轮正式评估命令

先配置融合程序的运行时库路径：

```bash
export LD_LIBRARY_PATH=/usr/lib/wsl/lib:$CONDA_PREFIX/lib/python3.7/site-packages/torch/lib:${LD_LIBRARY_PATH:-}
```

首先运行`refined depth + raw confidence`：

```bash
bash test.sh \
  ./checkpoints/experiment15_e_formal_stable_bce/model_000012.ckpt \
  --outdir ./outputs/experiment15_e/epoch12_refined_rawconf \
  --interval_scale 1.06 \
  --filter_method gipuma \
  --fusibile_exe_path ../../fusibile-master/build/fusibile \
  --use_sger_lite \
  --sger_max_residual_ratio 0.25 \
  --sger_residual_final_activation relu \
  --fusion_depth_source refined \
  --fusion_confidence_source raw --num_worker 4
```

上一条命令完全结束后，运行`raw depth + raw confidence`：

```bash
bash test.sh \
  ./checkpoints/experiment15_e_formal_stable_bce/model_000012.ckpt \
  --outdir ./outputs/experiment15_e/epoch12_raw_rawconf \
  --interval_scale 1.06 \
  --filter_method gipuma \
  --fusibile_exe_path ../../fusibile-master/build/fusibile \
  --use_sger_lite \
  --sger_max_residual_ratio 0.25 \
  --sger_residual_final_activation relu \
  --fusion_depth_source raw \
  --fusion_confidence_source raw --num_worker 4
```

两条命令必须依次运行，并保留不同的输出目录。本轮不使用`residual_calibrated`置信度，不调整融合阈值。
